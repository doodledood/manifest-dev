# Ticket store

- **Venue:** GitHub Issues, in `doodledood/manifest-dev`. The mapping is the plugin's GitHub venue reference (`ticket-up/references/GITHUB_STORE.md`).
- **Efforts:** each has a tracking issue labelled `effort` and `effort:<slug>`, and its Tickets are that issue's sub-issues.
- **Types:** the convention's default set: `bug`, `feature`, `refactor`, `docs`, `chore`.
- **Unattended execution:** none is configured. No automation assignee or escalation recipient is recorded yet. Record both here before any run starts unattended work on this store.
