# Surfaces v8

- The North Star holds only what decisions are judged against: what the project is for and whom
  it serves, how it tells progress, the principles it holds against evidence, and the bets it
  rests on. Six sections replace the nine fields — *Purpose* (with *For* and *Not for*), *Goal*,
  *Principles*, *How we know*, *What this rests on* and *Open* — followed by *Strategy choices in
  force*, a list of titles rebuilt from the decision records in effect with the area `Strategy`.
  A provenance note is one line.
- A line the owner would re-tune when evidence moves is a chosen option, not a position: it lives
  in a decision record, and a dated target lives in the destination of the effort pursuing it.
  The upgrade reshapes an existing North Star only on the owner's ruling, line by line; an
  unattended run only flags it.
- The ADR conventions reserve the area `Strategy` for a guiding choice and rebuild the North
  Star's *Strategy choices in force* list whenever such a record is written, superseded or
  retired.
- The North Star conventions file carries the new form, and the North Star line of the
  project-surfaces section names what the North Star holds and says the choices made along the
  way live in the decision records.
- A project without a North Star gains nothing beyond the conventions' reserved area.
