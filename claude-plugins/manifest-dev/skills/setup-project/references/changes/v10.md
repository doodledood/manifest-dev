# Surfaces v10

- Project surfaces distinguish an assignment from delegated decisions within it. Existing skill defaults remain; a scoped adjustment names the decisions delegated and retained without requiring an empty policy document.
- North Star and ADR maintenance can follow explicit delegation within an assignment. Owner-retained ends and bounds still need the owner; a met signpost supplies evidence, not authority. A ruling names its actual decider and delegation source.
- Setup shows concrete shared or personal text before persistence. When coordination is wanted, it reuses the existing work-store resolver and records designated evidence, notifications, and unavailable access; setup does not start operation.
