# Surfaces v14

- A decision record still on its own open branch is a draft, and deleting it, or changing which
  records it supersedes, narrows or amends, now takes back the restatus it made: each record it no
  longer changes gets back the Status and the `Enforced by` line it had before, and the index and
  the North Star's strategy list are rebuilt in the same change. Before, a deleted draft left the
  record it had superseded marked as superseded, so that decision dropped out of effect, and out of
  the strategy list, with nothing in force replacing it.
