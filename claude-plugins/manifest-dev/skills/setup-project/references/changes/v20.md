# Surfaces v20

- Starter sets changed: design. A new line: a surface says what each thing is through its form — a
  label on the thing, a mark, an order, a position — before a sentence does. A sentence about the
  surface itself stays only where no such form could carry what it says, and a finding that people
  do not understand a thing is repaired on the thing first.
- Four lines of the design set are reworded so that none of them asks for a sentence: an element
  stays only where its person would miss it; what the person will ask next is answered by what is
  shown, and by a note only where that cannot answer; a state says so, and why, in the fewest words
  that give both; and a figure shows its unit and what it counts, on the figure or its label. For a
  skill that covers design, offer the new line as a line it lacks, and each reworded line as a
  sharpening of the skill's line nearest it where that line does not already state the rewording
  whole, as `PRINCIPLES_SKILLS.md` → *With skills already in place* says.
