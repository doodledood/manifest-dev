# Starter principles: Writing

- Skill: `writing-principles`
- Offered when: the project writes text other people read — documents, or the words on its screens and in its messages.

## Lines

- A document, comment or description changes in the same change as the thing it describes — a stale description is believed, and it misleads whoever believes it. Yields for a decision record, which keeps what was decided at the time and is superseded rather than edited.
- A document opens with what its reader must decide or do, and background follows — readers stop early, and what comes last is read least. Yields for reference material people search rather than read in order.
- One thing goes by one term throughout the text the project shows and writes — a second word for the same thing reads as a second thing. Yields when quoting another source's term, marked as theirs.
- Text uses words its intended reader already knows — a word the reader must look up stops them at that word. Yields for a term the project coins, which is defined once where a reader first meets it.
- Only where the project keeps how-to documents: A how-to lets a reader new to the task complete it from the page alone, shown by such a reader having done so — the writer cannot see the step they kept in their head. Yields where the page links to the single home of a fact rather than copying it.
