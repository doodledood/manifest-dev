# Upgrading a project from v17: what v18 gives it

For each principles skill the project keeps, fit the starter sets for the areas it covers again under the
stricter rule in `../PRINCIPLES_SKILLS.md` → *With skills already in place*, and offer, once, the
starter lines it carries only in part — spread over several of its lines — placed as *With skills
already in place* says. For a skill that covers architecture, whose set changed in
v18, offer every starter line it lacks, the new line on widening an existing input before adding a
concept among them. A line the skill states whole is not offered, and a line on the other side of
one of the skill's lines is shown with both sides, the project's kept unless the person picks the
other. For an area the project works in that no skill covers, name the area in one line, as a later
setup does.

Record the newest surfaces version only after each applicable offer has an answer.
