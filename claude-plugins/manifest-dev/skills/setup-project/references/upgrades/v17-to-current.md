# Upgrading a project from v17: what v18 gives it

For each principles skill the project keeps, fit the starter set for its area again under the
stricter rule in `../PRINCIPLES_SKILLS.md` → *With skills already in place*, and offer, once, the
starter lines it now lacks: each line it carries only in part, spread over several of its lines,
as a sharpening of the nearest line or as a line of its own, and the new architecture line on
widening an existing input before adding a concept where a skill covers architecture. A line the
skill states whole is not offered, and a line on the other side of one of the skill's lines is
shown with both sides, the project's kept unless the person picks the other. For an area the
project works in that no skill covers, name the area in one line, as a later setup does.

Record the newest surfaces version only after each applicable offer has an answer.
