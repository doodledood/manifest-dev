# Reshaping a North Star from the nine fields into the six sections

A North Star in the older form keeps nine fields — *Diagnosis*, *What this rests on*, *Who it's
for*, *Promise*, *How they arrive*, *Money — or what it feeds*, *Winning, and the number watched*,
*Never* and *Open* — and those fields let chosen options in: a price, a channel, a launch plan, a
sequence of features. The current form, `../NORTH_STAR_FORMAT.md`, keeps only what decisions are
judged against and moves each chosen option to a decision record, where a later session meets it
as a choice it may revisit rather than as the purpose.

This reshape changes positions. Use an explicit assignment and delegation only for the lines
it covers; a general "apply everything" is not a grant to invent or replace retained ends. Show
the proposed lines and destinations for the owner's remaining rulings. An unattended run can
perform the authorized part and flags the rest with the lines it would move and where; it does
not invent missing choices or raise their evidence states.

## Ask for the end first

Before mapping any field, ask the owner, in their own words, what the person the project serves
is after, and of each answer ask "why does that matter?" until there is no deeper answer inside
the document. That end opens the new *Purpose*. The old *Diagnosis* usually names the barrier
the project's first feature removes; carried over as the purpose, it makes the purpose only as
wide as that feature, and every later feature sits outside it. So the *Diagnosis* becomes one
barrier in the way of the end, beside any others the owner names, never the purpose itself. A run
with an end already supplied uses it; with no authorized answer it leaves the end unresolved
and names what the owner must supply.

## Sort every line

Sort each position, each list entry and each provenance note by the test in
`../NORTH_STAR_FORMAT.md` → *What a line may be*:

- an end, a measure, a principle or a bet stays;
- a line the owner would re-tune when evidence moves is a chosen option;
- a value a measure should reach by a date is a dated target;
- a live metric reading leaves, since states carry dates;
- the part of a provenance note that tells how a position came to read as it does is history.

A line that names one example, setting, number, channel or path is nearly always a choice,
however long it has stood.

## Propose a destination for each line

| Line | Goes to |
|---|---|
| An end | *Purpose* (the end, then what is in its way, then *For* and *Not for*) or *Goal* |
| A measure | *How we know*, one per part of the goal, with its direction and any floor |
| A principle | *Principles*, phrased as what it rules out |
| A bet | *What this rests on*, the main bet first |
| A chosen option | the decision record that already holds it, named; otherwise a new record under the project's conventions. A guiding choice — one the project pursues its goal through and that other decisions derive from — carries the area `Strategy` |
| A dated target | the destination of the effort (the named body of work) pursuing it, where the project keeps a Ticket store; otherwise the decision record that holds the choice it serves |
| A live reading | the document or record that already holds it, or nowhere |
| History | cut; the note keeps its state, its grounding (for `empty`, what would fill it), its date and the titles of any records behind it |

The nine fields map to the six sections like this, line by line rather than field by field:

| Older field | Its lines go to |
|---|---|
| *Diagnosis* | *Purpose*, as one barrier in the way of the end the owner named, and *What this rests on* (its "if this were false" sentence, as the main bet) |
| *Who it's for* | *Purpose*'s *For* and *Not for* |
| *Promise* | *Goal* |
| *Winning, and the number watched* | *Goal* (what reaching it means for the project) and *How we know* (its number, as a measure); where that number counts use of a feature rather than progress on the end, the end's own measure is added beside it, `empty` with what would fill it |
| *How they arrive* | *Principles* where the owner holds a line against evidence; the rest are chosen options or readings |
| *Money — or what it feeds* | *Principles* where the owner holds a line against evidence; the rest are chosen options |
| *Never* | *Principles* |
| *What this rests on* | *What this rests on* |
| *Open* | *Open*, except a question that is an unmeasured part of the goal, which becomes an `empty` measure |

## Show it, then write what the owner rules

Show the proposed document beside the current one, with a table of every line that leaves it and
where it goes. Write only lines covered by the owner's rulings or explicit delegation — keep,
move, reword or drop. The retained lines wait for their owner, and no state rises in the move. Write the result as one act under the project's conventions:

1. the reshaped document;
2. a record for each chosen option that has none;
3. the area `Strategy` on each record that holds a guiding choice;
4. the *Strategy choices in force* list rebuilt from those records, with the signpost of each that has one;
5. one decision record of the reshape itself, naming each line that moved and where;
6. the index rebuilt.
