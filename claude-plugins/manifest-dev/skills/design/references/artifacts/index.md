# Artifact guides

Select by what the person does with the artifact, then read the linked guide. An app or page can contain several uses. Read the whole-app guide for decisions spanning screens, and add only the screen guides relevant to the work.

| Artifact | Main use | Guide |
|---|---|---|
| Landing or decision page | Understand an offering and decide what to do | [Landing pages](landing-pages.md) |
| App | Move among connected tasks without losing context | [Apps](apps.md) |
| Workspace, dashboard, or editor | Perform and monitor ongoing work | [Workspaces](workspaces.md) |
| Collection, catalog, or search results | Find something worth opening | [Collections](collections.md) |
| Reference or detail page | Retrieve a specific answer or inspect an item | [Reference](reference.md) |
| Article, report, or lesson | Develop an understanding | [Explanations](explanations.md) |
| Calculator, simulator, or interactive comparison | Discover relationships by changing inputs | [Exploration](exploration.md) |
| Onboarding, application, or checkout flow | Complete a task through dependent steps | [Guided flows](guided-flows.md) |
| Presentation or timed sequence | Follow an unfolding story | [Presentations](presentations.md) |
| Poster, diagram, or shareable figure | Grasp a message at a glance | [Graphics](graphics.md) |
