# Aliveness: reference facets

Motion is a cross-cutting design preference, not a separate artifact category. The selected facet matters more than the source product's category: a tiny status indicator and a large interactive scene can both teach how an interface feels alive, without justifying the same treatment everywhere.

| Reference | Selected facet | Scope |
|---|---|---|
| [Shazam — Dynamic Island listening](https://60fps.design/shots/shazam-dynamic-island-listening) | Small, polished ambient motion that communicates ongoing state. | Strong motion reference; not a model for moving an entire reading surface. |
| [Jitter — Interactive Components](https://jitter.video/template/interactive-components/) | Carefully composed transitions and responsive-looking component states. | Strong motion-craft reference. A preview demonstrates appearance, not the usability of a production control. |
| [Octoglow — Maxime De Greve](https://maximedegreve.com/experiments/octoglow) | The original expressive-web seed: visual character and a sense of life. | Inspiration, not an approved universal layout or functional requirement. |
| [Cosmos](https://www.cosmos.so/) | Refined, content-first visual treatment with little surrounding chrome. | Visual-only app reference; screenshots did not establish interaction quality. |

The spectacle limits live with their artifacts: [Active Theory in landing pages](landing-pages.md#spectacle-boundary) and [Dithering in long-form explainers](long-form-explainers.md#visual-intensity-boundary). Their craft was admired; their intensity is not the default.

[Kinopio](https://kinopio.club/) was not selected for its intentionally rough, handmade visual language. Novelty alone is not the desired personality; polished execution remains part of this profile.
