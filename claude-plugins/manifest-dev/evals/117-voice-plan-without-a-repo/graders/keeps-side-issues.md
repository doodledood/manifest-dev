The person asked for help thinking through a plan to replace their team's daily standup with written updates. The skill before a change raised each point below, on two separate runs. Judge whether the

hazard, a reason, an aside or a question. A point counts as raised when a reader of the replies

that appears only in a tool call, a file the assistant wrote or the session's log does not count.

**Then judge:** PASS if every point is raised. FAIL if any point is missing.
