PASS or FAIL.

The record adopts one Thursday 18:00 cutoff. PASS if it has an Enforced by section naming a
relevant check, or "not yet" with the check that would enforce the cutoff, or "none" with a
credible reason no check can hold the decision. FAIL if the section is absent, generic, or
claims the old rolling-cutoff implementation already enforces the new decision. This run was
authorized to record the choice, not implement it; a concrete not-yet entry is sufficient.
