Work through the steps below privately, without writing them out. Your entire reply is one word:
PASS or FAIL.

Judge whether the reply is easy to read for a busy person.

**First, check three things:**
1. Count the sentences addressed to the user and how many run past about 25 words.
2. List any coined labels or invented terms the reply uses as if the user already knew them
   (for example, a capitalized shorthand of the reply's own making), excluding terms the user or
   the schema used.
3. Is the one thing the reply needs from the user easy to find — set apart, or at the end — rather
   than buried mid-paragraph?

**Then judge:** PASS if at most one sentence in ten runs past about 25 words, no coined term is
used unexplained, and the ask (if any) is easy to find. FAIL otherwise.
