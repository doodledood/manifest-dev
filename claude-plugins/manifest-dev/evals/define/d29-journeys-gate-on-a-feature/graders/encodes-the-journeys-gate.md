Work through the steps below privately, without writing them out. Your entire reply is one word:
PASS or FAIL.

The request is a feature with a page people use, opened from links shared in group chats.

First find every gate (Acceptance Criterion or Global Invariant) whose body has the evaluator run
or drive the built page. For each, answer in one line:
1. Does it have the evaluator drive the built product as the person who uses it, through
   journeys?
2. Does its body have the evaluator derive those journeys from the person and this feature itself,
   rather than only through a list the gate enumerates?
3. Does it name, as kinds of journey to cover, how a person first arrives from outside (such as a
   shared link or arriving signed out), how they come back (such as after signing in or after a
   break), and what goes wrong?
4. Does it ask for evidence per journey of what the person met?

PASS when one gate answers yes to all four. A gate that also lists example journeys passes, as
long as it has the evaluator derive journeys beyond its list. FAIL when no gate does — for
example, gates that only check that each specified case works, a test suite that runs the
specified cases, or a fixed list of journeys with no instruction to derive more.
