# Alder Library Saturday-hours proposal

Create a five-slide HTML talk deck for a 90-second presentation to library trustees. The speaker asks them to authorize a six-week pilot of longer Saturday hours. This is a projected presentation, not a dense reading document. A trustee opening it later on a phone must still be able to navigate and read its argument.

Use only these fictional scenario facts:

- Alder Library currently opens on Saturday from 10:00 to 14:00.
- The proposal extends closing to 16:00 for six consecutive Saturdays.
- The extra staffing costs $180 per Saturday: $1,080 for the six-week pilot.
- An opt-in survey received 120 responses; 72 requested later Saturday hours. It was not a representative sample.
- Manual door counts recorded 400 visits between 12:00 and 14:00 across the last four Saturdays. These are visits, not unique people, and do not measure demand after 14:00.
- Two volunteers have expressed interest, but their availability is not confirmed. The pilot must have confirmed staffing before it starts.
- During the pilot, count visits from 14:00 to 16:00, collect visitor feedback, and review staffing feasibility before deciding whether to continue.

The recommendation is a bounded pilot, not a claim that extending hours is already proven effective. Preserve that distinction and the material limits of the evidence. Choose the storyline, visual evidence, layout, type and pacing yourself. Aim for an engaging, coherent argument suited to a room rather than five screens of speaker notes.

Provide working previous/next controls and keyboard navigation. No autoplay is required. It must be possible to return to a slide without losing the sequence. Show enough position/orientation for the presenter to know where they are.

Delivery: one offline HTML file with embedded CSS and JavaScript; no external fonts, images, libraries or network requests. Use native HTML, CSS and SVG where useful. Support a desktop presentation viewport and phone reading with keyboard and pointer input. No existing visual identity or slide template is supplied.
