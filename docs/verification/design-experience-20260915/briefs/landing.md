# Relay landing page

Create a complete, self-contained HTML landing page for Relay, a fictional project-handoff tool for small design studios. The visitor is a studio lead arriving from a colleague's link on a laptop or phone. They need to decide whether Relay solves their handoff problem and try a small example.

Product facts:

- Relay keeps a project's decisions, open questions and next owner on one shared handoff page.
- A recipient can acknowledge the handoff, so the sender can see that it was received.
- The fictional offer is $12 per workspace per month, with a 14-day trial and no credit card required.
- This is a product concept, not a live service. Do not invent customer counts, testimonials, integrations or measured benefits.

The primary action is **Try a handoff**. It must lead to a working local demonstration, not a dead link or a real signup. The sample project is **Harbor identity**:

- Decision: use the wordmark without the wave symbol.
- Open question: does the packaging need a bilingual version?
- Next owner: the production designer.
- Next step: prepare a print proof by Thursday.

The visitor can acknowledge the example and undo/reset that acknowledgement. Make clear that this changes only the demo. Include the price and terms where a visitor can find them. Choose the composition, imagery, typography and interaction treatment yourself; the page should have a deliberate identity suited to the product rather than feel like a wireframe.

Delivery: one offline HTML file with embedded CSS and JavaScript; no external fonts, images, libraries, network requests or real submissions. Use native HTML, CSS and SVG where useful. It must work on desktop and phone with keyboard and pointer input. No existing brand system or visual mock is supplied.
