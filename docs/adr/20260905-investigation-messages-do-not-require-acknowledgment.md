# ADR: Investigation messages do not require acknowledgment

## Status
Accepted

## Area
figure-out

## Context

The one-claim turn budget can require a new user message before discoverable work continues. A compulsory existence question has the same effect when the evidence already settles whether a proposed element earns its place.

## Decision

Budget presentation by message, while the agent owns investigation through discoverable questions. Yield for a concrete human contribution or a completed Read. Resolve existence from evidence before asking for judgment. Acknowledgments continue the work; they are not approval to implement it.

## Alternatives Considered

- Require a question after every finding: invents decisions where the user has none to make.
- Remove the attention budget: allows useful investigation to arrive as an unreadable report.

## Consequences

### Positive

- Short messages preserve attention without requiring procedural replies.

### Negative

- The agent must distinguish a necessary user contribution from a question it can investigate.
