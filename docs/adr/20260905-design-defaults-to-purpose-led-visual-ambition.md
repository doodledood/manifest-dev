# ADR: Design defaults to purpose-led visual ambition across genres

## Status
Accepted

## Area
Design skills

## Context

The design builder could produce a clear, usable artifact without a compelling visual direction. Its treatment rules defaulted tools, dashboards, and documents to utilitarian work and reserved the creative-direction procedure for editorial treatments. The evaluator checked distinctiveness only when an artifact claimed it. Functional correctness could therefore satisfy both sides while the user still needed another request to make the result visually engaging.

Purpose and audience already precede layout in the six-decision flow. The missing requirement is to use that understanding to pursue visual impact in every genre. Everyday tools still need fast repeated actions, serious reports still need truthful evidence, and existing design systems still govern the visual language.

## Decision

Visually striking, memorable work that excels at its purpose is the default outcome of the design skill. A clear, usable layout alone does not complete the design goal. Genre determines how the ambition is expressed, including density and ornament, without making visual quality optional.

The existing register decision also commits to a creative direction informed by the purpose, audience, and task model. User requirements and existing design systems are resolved before that choice. This replaces the utilitarian/editorial permission split; it adds no mode or discovery stage. The shared references describe how feeling fits the use context rather than dividing genres into those that may and may not carry a designed point of view.

The reviewer evaluates the same goal in every genre. A visual-ambition finding needs rendered evidence of an unresolved direction and a concrete improvement within the brief. Familiar patterns, restrained styling, and required design-system components are not defects. The evaluator judges the execution of the chosen direction rather than substituting its own taste.

Functional floors, truthful information, and the existing prototype-weight boundary remain requirements. Prototype effort stays concentrated on the surface being judged; a new visual goal does not authorize polishing incidental parts.

## Alternatives Considered

- **Keep visual ambition opt-in:** preserves the existing rules, but leaves the second request as part of normal use even when the user invoked design to improve the artifact.
- **Default every genre to exuberant storytelling:** makes the direction forceful, but imposes the wrong experience on repeated work and serious decision material. Purpose and use context must shape the expression.
- **Change only the builder's opening goal:** adds little text, but leaves contradictory treatment rules and an evaluator that can still waive the same requirement.
- **Add a separate discovery stage or visual-impact mode:** duplicates the existing purpose/task-model decisions and makes a desired default something the user must select.

## Consequences

### Positive
- Creative ambition is part of ordinary building and review across artifact types.
- Purpose and audience direct the visual treatment before tokens and components are chosen.
- The rule becomes consistent by replacing conditional instructions rather than adding another workflow.

### Negative
- Visual impact remains a judgment call; reviewers must ground findings in the render and the brief rather than demand arbitrary novelty.
- Instruction and scenario review can check consistency but cannot establish improved generated designs or delayed recall. The previously deferred effectiveness evaluation remains deferred.
