# #7 Accented names no longer break the import

The import failed on the servers for any customer whose name has an accent, such as "Zoë".

## Debt left

None.

## Repaired, no check added

- `load_customers` in `importer.py` read the customer file in the platform's default text
  encoding, which is ASCII under the servers' C locale; a name with an accent raised
  `UnicodeDecodeError`. Fixed by reading it as UTF-8. One-off: it is the only place the project
  reads a text file.
