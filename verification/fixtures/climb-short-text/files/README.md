# tidyhosts

tidyhosts is a command line tool that can be used in order to perform the sorting, the
de-duplication and the commenting-out of entries that are present in a hosts file, which is a
file that is used by operating systems for mapping hostnames to IP addresses, and it also has
the ability to make a backup before any changes are made to it.

## Install

    pip install tidyhosts

## Use

    tidyhosts /etc/hosts --backup
