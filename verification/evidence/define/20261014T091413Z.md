**The problem it addresses.** Organizers have no way to see what a member has borrowed over time. The repo is further behind than the request suggests: `checkout` and `return` only print their own name and save nothing, `renew` doesn't exist, and there are no tests.

**The plan, in order:**
1. **A way to check the commands it touches.** A small harness runs Shelfnote in a throwaway folder and keeps what happened (output and resulting data files). It comes with a short map of the four commands this change touches, and `CLAUDE.md` will point to it.
2. **Checkouts and returns get logged.** Each one writes an entry (member, action, book, UTC time) to `data/activity.json`, and `shelfnote activity --member X` prints that member's history, oldest first.
3. **Renewals get logged.** A new `renew --book` command records a renewal on an open loan.

**Guardrails for a log that runs for years:**
- Entries are only ever added, never removed or rewritten.
- If a write fails partway, the file keeps its earlier contents.
- If the file is corrupt, commands stop with an error instead of overwriting it.
- There's a load test with about 20 years of activity (18,000 entries).
- Each data file can only be written by one piece of code.
- A new decision record explains why the log is stored this way.

**Decisions I made that you may want to change** (there were no saved preferences to go on):
- **Who a return or renewal belongs to.** It's taken from whoever has the book on loan, so the documented `return --book` stays as is. This means checkout now really saves loans. The other option was adding `--member` to `return`, which changes the documented commands and could log the wrong person.
- **No rotation or archiving.** It's one file kept forever. Yearly archive files would add a second place to read from and more ways to lose old years. The "20 years" size is my estimate, built from the existing note that a club has a few hundred loans.
- **Renewal sets no due date.** Nothing in the repo defines a loan period, so it only records that the renewal happened.

Smaller defaults are listed as assumptions in the file: standard-library tests, exact-match member names, refusing to check out a book that's already on loan, and no backfill.
